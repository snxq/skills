# code-explain

代码解读专家，帮助用户理解代码（而非代码审查）。解析代码意图、执行流程、数据流转、关键设计、隐含前提与坑点。

支持的功能：
- 按固定结构输出解读：一句话摘要 → 整体执行流程/数据流 → 核心模块拆解 → 关键设计点 → 隐含前提与坑点 → 疑问
- 优先讲意图、其次讲实现，控制专业术语密度，复杂逻辑画文本流程图
- 代码片段不完整时主动列出缺失上下文假设，不强行脑补
- 默认不做代码 review，不按 CRITICAL/HIGH 风险等级罗列问题；用户主动要求时才切换评审模式

## 安装

```bash
cp -r code-explain ~/.claude/skills/
```

## 使用

安装后，在 Claude Code 中直接用自然语言触发：

- `看懂这段代码`
- `解释一下这段代码`
- `帮我理解这个函数`
- `梳理这段代码的逻辑`
- `这段代码做了什么`
- `解读这个 diff`
